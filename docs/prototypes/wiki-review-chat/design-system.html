Design System · April 2026

A calm, considered system for a thinking partner.

Advisor helps PMs, consultants, and founders carry a project's full context. The interface should feel like a well-kept notebook — quiet by default, generous with whitespace, precise about evidence. AI is present but not loud; sources are the hero.

01 — Principles

Five rules the system holds itself to.

Each surface, component, and AI moment should pass these tests before it ships.

P · 01

Evidence over confidence.

Every claim the AI makes carries a numbered citation back to the source. No ungrounded prose.

P · 02

Memory needs consent.

Durable updates appear as drafts in a review surface. The user is always the one who commits.

P · 03

Hide the machinery.

Tool calls collapse into a single line. Prompts, chunks, and embeddings live behind a quiet "show details".

P · 04

Whitespace is structure.

Density is a last resort. The product has time to think; the layout should breathe like it.

P · 05

Two voices, one page.

Sans for prose, mono for evidence — file paths, citations, timestamps, tool names, IDs. The mono is the system whispering "this is real, you can verify it."

02 — Color

Warm ink on warm paper, plus one accent.

Neutrals carry slightly warm chroma so the surface feels paper, not screen. Accent does the work of structure and meaning — there is no decorative color.

Accent directions — pick one, the system follows

Electric

Bright, saturated blue. The default. Confident and crisp — reads as a modern, intelligent product.

Iris

Deep periwinkle. Quieter and more editorial — the calm alternative if Electric feels too loud.

Moss

Forest sage. Reads as "advisor" — calm, organic, low-stakes. Best for consultants and operators.

Ember

Terracotta. The warmest, most human option. Best if the brand wants to feel personal and bespoke.

Click a swatch — the entire system updates live. Same for theme toggle in the top bar.

03 — Type

Geist for prose, Geist Mono for evidence.

One typeface family, two voices. The mono shows up wherever the system is being literal — file paths, citations, timestamps, tool names, IDs. Never decorative.
