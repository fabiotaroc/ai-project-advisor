# Proposal: Wiki Rich Diff Review

**Goal:** make proposed wiki updates reviewable in a spacious, source-grounded diff experience before they change canonical project memory.
**Domain(s):** `wiki`, `chat`

## Summary

Pending wiki edits should move from cramped cards and append-only mental models toward a unified review drawer that users can open from source detail pages, chat proposals, and eventually wiki documents. The review experience should show proposed additions and updates against the canonical doc with nearby context, clear source evidence, and per-change accept/reject controls. The downloaded prototype is useful directional inspiration for the review-drawer concept, but the product should adapt the pattern to the existing app's calmer layout and current wiki/chat/source surfaces.

## Out of Scope

- Redesigning the full chat page, source page, or wiki page.
- Introducing a visible developer-style Git or version-control model.
- Automatically applying wiki changes without explicit user review.
- Full support for deletion proposals from source ingestion in the first UI pass.
